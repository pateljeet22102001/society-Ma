# Society Management

A modern web app for housing societies to manage flats, maintenance, income, expenses, events, and reports.

**Live:** [society-man-jeet.vercel.app](https://society-man-jeet.vercel.app)

## Features

- Secure login
- Dashboard overview
- Wings & flats management
- Income (Aavak) & expenses (Javak)
- Maintenance billing & payments
- Event Hisab
- Reports (PDF / Excel)
- Mobile-friendly admin panel

## Tech Stack

- Next.js · TypeScript · Tailwind CSS
- Supabase (Auth + PostgreSQL)
- Hosted on Vercel

## Quick Start

```bash
npm install
cp .env.example .env.local
npm run dev
```

Add your Supabase keys in `.env.local`, then open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev      # development
npm run build    # production build
npm run start    # run production build
npm run lint     # lint
```
